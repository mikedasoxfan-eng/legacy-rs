# Round 10 entity class audit

The round-9 report is the starting status. Original source diffs for all five
remaining classes are retained in `target/entities10-<Class>.diff`. No original
Java, shared fixture, Beta 1.7.3 or integrator renderer file is edited.

| Class / methods | Literal port and live use | Original-bytecode proof |
|---|---|---|

| Item icon and name delegation | Final icon lookup dereferences the stack before calling the virtual damage callback; stat name calls the virtual name once before translation; block names stay in the existing block registry | `itembase10`: virtual icon callback count, damage, null and failure order; virtual nullable names; base untranslated keys and callback forwarding |

ItemBlock's class dispatch is complete at its API boundary, but the class remains
Not done in the report and is not counted as a completed class. Its broad replay
failure belongs to the retained world callback, not a swallowed or normalized
ItemBlock result. SpawnerAnimals live terrain population and ItemStack's
player-owned alias/delegation audit remain untouched. No GPU validation is
claimed. Full `tools/verify181.sh` remains for integration after merge.
