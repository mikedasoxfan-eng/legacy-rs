# Release 1.0 world port, round 3

**88 Done; 51 Not done**, all 139 requested classes in task order. Done requires the represented Release delta plus executed exact original-bytecode evidence. Known source/model gaps and insufficient checks remain Not done; successful isolated tests do not certify an entire provider or NBT graph.

New harness: `tools/verify_r10world3.sh`, appended to `tools/verify10.sh` before final `pflush`, uses original Mojang Release bytecode through `tools/oracle10`, with individual `== r10world3` sections, retained failure status and output directory creation. `WORLD3_GROUP` supports additions/core/terrain/features/world/structures; no `set -e`. Only harness Mode classes are compiled; no recompiled game implementation supplies expected values. The local ignored `tools/retromcp-r10` junction points at the existing primary checkout's original source/jar.

Production fixes: mineshaft candidate chance 1/100 (was 1/80) and corridor side-branch depth below 8 (was below 10); independently mutable World height/shift/mask/sea-level fields and query/light/spawn/random-tick consumers; village ground height/sea level forwarding; spike height cap; process-wide biome decoration guard; Profiler header name verified against original bytecode (the decompiler's trailing-dot name was misleading); hash-map entry string forms. Other active Release generation/structure code was already represented by merged rounds and is now measured against the oracle.

Fixture repairs are separate from production fixes: returned GenLayer array duplication, End generator in the inherited Sky diagnostic, all 16 sky-colour biomes, live loaded entities rather than dragon parts, Java class names MagmaCube/Mooshroom versus registry names LavaSlime/MushroomCow, removed save-size getter mapping to the retained last-played getter, Release oracle save input paths, and new-room fields omitted by the inherited stronghold dump. Dedicated new portal/chest fixtures compare the actual room blocks, loot, one-shot flags and RNG; omitted legacy fields were not used to mask a production difference.

The report does not certify the whole `tools/verify10.sh` aggregate. Remaining gaps include NBT named/shared/null/UTF-16 graph semantics, queued-save aliases and I/O failures/scheduling, nullable provider wrappers, complete mutable-height storage, biome-cache references and untested rendering/interface classes. No old-version crate, oracle or verification suite was edited. No external-area production file was edited.

Validation and evidence: `target/r10-world3-verified.log` (full suite), `target/r10-world3-additions.log` (final additions rerun); original per-case logs under `target/r10/world3`, scalar trace sidecars in `tools/oracle10/out`, and independent Rust comparisons/snapshots under `target/r10/compare`.
