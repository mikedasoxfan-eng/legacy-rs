# legacy-rs v3.1.0 verification

Release date: October 9, 2026. This release adds Minecraft 1.1 to the existing Beta 1.7.3, Beta 1.8.1 and 1.0 clients.

## Source provenance

The completed implementation was committed at `f94511b3314290765336c3a37fd501538de71310`. The runtime validation candidate was `b4eef854dd54f72ab75af309113ca5e7054635f7`; its source and evidence hashes remain in [final-validation.json](../r11-progress/final-validation.json).

Release preparation changes the workspace package version from 3.0.2 to 3.1.0, its lockfile entries, the README and documentation. Game implementation files and registered original-code evidence remain unchanged. The release tag `v3.1.0` identifies the final committed documentation and package metadata.

## Runtime evidence

The completed 1.1 candidate passed 67 retained client tests, 114 simulation tests, 159,452 original potion-name/tooltip calls, 65,550 original world-name NBT cases, 96 original Unicode world-creation callbacks and 3,021 achievement tooltip callbacks. Native first-save/reopen/list/rename/delete checks passed. The cross-version workspace library batch passed 249 tests.

These are retained runtime results. The metadata-only release rebuild separately checks packaging; it does not claim a fresh full oracle rerun for every older version.

## Release package checks

The release package report and checksums are recorded in `v3.1.0-artifacts.json` after the build completes. [Package log](v3.1.0-package.log) retains the release workspace build, version output and headless help dispatch for each supported Minecraft version.

The ZIP contains `beta.exe`, the optional `give.exe` inventory editor, installation notes and SHA-256 checksums. The standalone game executable and inventory editor are also published separately. No Mojang assets or original-game oracle fixtures are included.
